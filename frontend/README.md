# SteamMCP Frontend

React/Vite frontend for the SteamMCP AI game recommendation API.

## Run locally

```bash
npm install
npm run dev
```

The frontend defaults to:

```text
https://steammcp-s5qu.onrender.com
```

To use another backend, create `.env` from `.env.example`:

```env
VITE_API_URL=https://your-api-url.example.com
```

## Build

```bash
npm run build
```
